# Elephant Goldfish Review

Один агент (elephant) помнит контекст и пишет план. Другие (goldfish) с нулевым контекстом проверяют план по углам.

## Правило

- Goldfish не видят чат/контекст.
- Проверяют: есть ли более простой способ; понятен ли план без контекста; масштабируемость; достаточно ли ясно для реализации без угадывания.
- Результат объединяется в один отчёт для пользователя.

## Чек-лист

- [ ] Goldfish без доступа к чату.
- [ ] План проверен по нескольким углам.
- [ ] Отчёт объединён в один документ.
