# Altitude Prompt

Давать модели цель (результат), а не задачу. Пусть модель сама разбирает задачи.

## Правило

Вместо «сделай X» → «сделай так, чтобы Y» (цель). Модель работает на более высоком уровне абстракции.

## Пример

- Плохо: «Построй панель отчётов с данными».
- Хорошо: «Построй панель, которая отвечает на вопросы, которые мы задаём себе каждую неделю».

## Чек-лист

- [ ] Сформулирована цель (что нужно получить), а не шаги.
- [ ] Агент сам разбивает цель на задачи.
- [ ] Результат проверяется по цели, а не по факту выполнения.
