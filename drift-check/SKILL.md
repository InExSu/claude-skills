# Drift Check

После реализации проверить, где код больше не соответствует плану/README.

## Правило

- Запустить проверку по всем readme/планам.
- Список расхождений и багов.
- Предложить исправления.

## Чек-лист

- [ ] Проверены все планы/readme.
- [ ] Составлен список расхождений.
- [ ] Предложены исправления.
