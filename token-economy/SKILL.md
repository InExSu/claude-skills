# Token Economy (Карпатый style)

## Главный принцип

> **Каждый токен должен работать. Если токен не работает — он лишний.**

---

## Для промптов

### 1. Убирай вежливость
```yaml
# ❌ ПЛОХО (14 токенов)
"Пожалуйста, не могли бы вы помочь мне написать функцию для сортировки массива?"

# ✅ ХОРОШО (3 токена)
"Напиши sort(arr)"
```

### 2. Избегай повторов
```yaml
# ❌ ПЛОХО
"Ты опытный разработчик с 10-летним стажем. Как опытный разработчик, ты знаешь..."

# ✅ ХОРОШО
"Ты Senior dev. Напиши код."
```

### 3. Используй структурные маркеры
```yaml
# ❌ ПЛОХО
"Вот контекст: у нас есть функция, которая принимает массив чисел и возвращает сумму. Нужно написать тесты для неё."

# ✅ ХОРОШО
"## Контекст: sum(arr) → number
## Задача: тесты"
```

### 4. Формулируй как команду
```yaml
# ❌ ПЛОХО
"Я хотел бы попросить тебя подумать о том, как можно было бы оптимизировать этот код..."

# ✅ ХОРОШО
"Оптимизируй код: [code]"
```

### 5. Давай примеры вместо описаний
```yaml
# ❌ ПЛОХО (описание)
"Функция должна принимать массив чисел, проверять каждый элемент на то, что это число, затем суммировать только чётные числа, и возвращать результат..."

# ✅ ХОРОШО (пример)
"sumEven([1,2,3,4]) → 6"
```

## Для ответов

### 1. Ответ — только код (без пояснений)
```yaml
# ❌ ПЛОХО
"Вот функция, которая решает вашу задачу. Я использовал map и filter для обработки данных..."

# ✅ ХОРОШО
function sumEven(arr) {
  return arr.filter(x => x % 2 === 0).reduce((a,b) => a+b, 0)
}
```

### 2. Комментарии — только где надо
```yaml
# ❌ ПЛОХО
// Эта функция принимает массив чисел и возвращает сумму чётных
function sumEven(arr) { ... }

# ✅ ХОРОШО
function sumEven(arr) { ... }  # O(n)
```

### 3. Не объясняй очевидное
```yaml
# ❌ ПЛОХО
"Используем цикл for для перебора элементов массива..."

# ✅ ХОРОШО
(просто код)
```

## Для кода

### 1. Короткие имена (но осмысленные)
```yaml
# ❌ ПЛОХО
function calculateTotalPriceForAllItemsInTheShoppingCart() { ... }

# ✅ ХОРОШО
function calcTotal(items) { ... }
```

### 2. Минимум абстракций
```yaml
# ❌ ПЛОХО (фабрика фабрик)
new FactoryBuilder().createFactory().build()

# ✅ ХОРОШО
new Factory()
```

### 3. Inline вместо переменных
```yaml
# ❌ ПЛОХО
const result = calculate(data)
const formatted = format(result)
const output = print(formatted)

# ✅ ХОРОШО
print(format(calculate(data)))
```

### 4. Сокращай условные конструкции
```yaml
# ❌ ПЛОХО
if (condition === true) { ... }

# ✅ ХОРОШО
if (condition) { ... }
```

### 5. Используй однострочники
```yaml
# ❌ ПЛОХО
const result = []
for (let i=0; i<arr.length; i++) {
  result.push(arr[i] * 2)
}

# ✅ ХОРОШО
arr.map(x => x*2)
```

## Для документации

### 1. TL;DR в начале
```yaml
# ❌ ПЛОХО
"Данный документ описывает архитектуру системы..."

# ✅ ХОРОШО
"# Архитектура (TL;DR: микросервисы + Redis)"
```

### 2. Таблицы вместо текста
```yaml
# ❌ ПЛОХО (текст)
"Функция принимает параметр name, который должен быть строкой. Также она принимает параметр age, который должен быть числом..."

# ✅ ХОРОШО (таблица)
| param | type | required |
|-------|------|----------|
| name  | str  | yes      |
| age   | int  | no       |
```

### 3. Ссылки вместо копирования
```yaml
# ❌ ПЛОХО
"См. код из примера: function foo() { ... } (100 строк)"

# ✅ ХОРОШО
"См. [examples/foo.js](./examples/foo.js)"
```
