# Depth Prompt

Просить агента не просто выполнить задачу, а сделать её максимально качественно.

## Правило

Добавлять к запросу: «сделай настолько хорошо, насколько возможно». Агент начинает проверять крайние случаи, обрабатывать ошибки, писать тесты.

## Чек-лист

- [ ] Запрос содержит требование к качеству, а не только к результату.
- [ ] Агент проверяет граничные случаи и ошибки.
- [ ] Добавлены тесты/проверки.
