# Range Prompt

Описывать приложение по тому, что оно делает для людей, а не по тому, что оно есть. Затем просить агента spawn субагентов по областям.

## Правило

1. Описать приложение глаголом: «его работа — X».
2. Попросить агента посмотреть на приложение с как можно большего числа углов.
3. Агент spawn субагентов, каждый проверяет свою область.

## Чек-лист

- [ ] Описание приложения через действие (глагол).
- [ ] Субагенты по специализированным областям.
- [ ] Каждый субагент предлагает и внедряет исправления.
